# Problem: Reverse a String (Easy)

**Link:** LeetCode — Reverse String

## Approach

I used the two-pointer technique to reverse the string. One pointer starts from the beginning and another starts from the end. I swap the characters at both positions and move the pointers toward the center until the string is reversed.

## Complexity

* **Time:** O(n)
* **Space:** O(1)

## Notes

I tested the solution locally using two test cases. The first test case uses the string `hello`, while the second test case contains a single character. A single-character string remains unchanged after reversal.
